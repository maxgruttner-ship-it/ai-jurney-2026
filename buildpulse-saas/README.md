# 🏗️ BuildPulse AI - Vertical SaaS for Construction-Tech

BuildPulse AI ist eine All-in-One-Plattform für die moderne Baubranche. Sie kombiniert Projektmanagement, Angebotserstellung, Maschinenvermietung, Zeiterfassung und eine KI-gestützte Verzögerungsvorhersage.

## 🚀 Features
- **SaaS Dashboard:** Alle KPIs auf einen Blick (Auslastung, Budgets, Verzögerungen).
- **Angebotserstellung:** Schnelle Kalkulation von Bauprojekten.
- **Bauplan-Freigaben:** Digitaler Workflow für Architekten und Bauleiter.
- **Maschinenvermietung:** Smarte Verwaltung des Fuhrparks.
- **Mitarbeiter-Zeiterfassung:** Einfaches Loggen von Arbeitsstunden.
- **KI-Verzögerungsvorhersage:** Risiko-Analyse basierend auf Wetter, Lieferketten und Personal.

## 🛠️ Lokal starten
1. Repository klonen: `git clone <dein-repo-link>`
2. Abhängigkeiten installieren: `pip install -r requirements.txt`
3. App starten: `streamlit run app.py`
